CAFE KOLKATA LANDING PAGE

Files:
- index.html: Complete responsive one-page website. CSS and JavaScript are included in this file.

HOW TO PREVIEW
1. Open index.html in a modern browser, or open the folder in VS Code and use Live Server.
2. Internet access is needed for Google Fonts, remote Unsplash images, and the embedded map.

BEFORE PUBLISHING — REPLACE SAMPLE CONTENT
- Address and Google Maps embed / directions URL
- Phone number, email, WhatsApp number, social profile URLs
- Opening hours and menu items/prices
- Testimonials and customer portraits (use real, approved reviews and images)
- Connect the message form to a backend or form service. It is currently demo-only and does not send messages.
- Add real booking functionality if customers should reserve a table online.

This is a static front-end starter, not a deployed website. Images and fonts load from external services.
